# TradeLog\n\nTradeLog is a private-first trading journal UI that can be published with GitHub Pages.\n\n## Static build\n\n- Dashboard, journal, strategies and profile views\n- Trade entries saved in the browser with localStorage\n- Public-profile UI\n- Hypothetical scenario calculator\n- Light/dark mode\n- Custom accent and logo colors\n- Monochrome mode\n- Animated RGB border with wave/breathe effects\n- Responsive desktop/mobile layout\n- No external runtime dependencies\n\n## GitHub Pages\n\n1. Open Settings → Pages in this repository.\n2. Under Build and deployment, choose Deploy from a branch.\n3. Select main and / (root).\n4. Save.\n5. The project site will be available at https://unbloating.github.io/Tradelog/ after deployment.\n\n## Multi-user production features\n\nGitHub Pages is a static host. It cannot securely provide user accounts, databases, private cloud journals, or OAuth secrets. A true public multi-user service needs a backend for accounts/sessions, usernames, database-backed trades and strategies, privacy controls, sharing/following, Discord/Instagram/X OAuth, secure token storage, rate limiting, validation and abuse protection. Never put OAuth client secrets or database credentials in index.html.\n\nThe current build deliberately keeps journal data local to each browser until a backend is connected.\n\n## Disclaimer\n\nTradeLog is a journaling and educational tool. Scenario calculations are hypothetical and are not forecasts or guarantees of trading results.\n
